# Changelog

## 1.0.0 — 2026-10-15

First clean source release for personal study on Windows and Chrome/Edge.

Includes website capture with explicit permission, video study time, AI practice, summaries, scores, retakes, question feedback, local transcription, timestamp links and backup/restore. Personal records and credentials are excluded.

The browser extension retains manifest version 0.2.0 and internal build r10. The repository snapshot is version 1.0.0.
